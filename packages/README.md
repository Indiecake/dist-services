# Shared Packages

This folder contains reusable libraries shared across services.

- `contracts`: shared event and command contracts.
- `contracts`: shared event envelopes, versioned contract helpers, and messaging examples.
- `telemetry`: tracing and metrics helpers.
- `database`: migration and database utilities.
- `kafka`: shared topic definitions, partition key conventions, and future producer/consumer helpers.
- `config`: shared environment configuration helpers.
